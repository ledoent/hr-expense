On a paid advance report with a remaining amount:

- **Clear Advance** creates a draft clearing report, one line per advance line
  that carries a *Clearing Product*, prefilled with that line's remaining
  amount. Adjust the lines freely — the per-line advance links stay
  authoritative, and the report-level link follows them.
- **Return Advance** (visible to users with *Full Accounting Features*, like
  the per-expense button) opens Register Payment over the report's open
  advance lines. With several advance lines, one payment is registered per
  advance — grouping them into a single payment is not offered, because a
  grouped payment could not say which advance line it returns and the
  per-line residuals would stop tracking. To return a single line, use the
  button on that expense.
